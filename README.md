# 秦统一至汉初 · 历史战争地图

前 230 年至前 180 年的单页历史可视化网站。用户可拖动或播放时间轴，查看战争事件、活动云团和行军路线随时间变化，并阅读带来源和可信度标记的事件详情。

## 已实现（本地发布候选版）

- Next.js、TypeScript、Tailwind CSS 项目骨架；
- 基于 Natural Earth 1:110m 数据的本地中国地理底图（无外部服务或密钥）；
- 33 个结构化战争、战役、起义、边疆与政权重组事件，覆盖秦灭六国、秦末起义、楚汉战争与汉初；
- 年份范围 `-230` 至 `-180`、中文纪年、播放/暂停、0.5/1/2/4 倍速和阶段跳转；
- 地图事件节点、统计面板、详情面板；
- 战争云团聚合、综合/云团/节点模式、动效开关和地图缩放；
- 10 个关键事件的行军路线或多地点过程表达；
- 密集事件节点错位与按需标签显示，避免高密度年份文字堆叠；
- 桌面端固定高度详情侧栏、移动端重排、键盘操作和低动效支持；
- 时间筛选、边界处理、坐标、来源、重复 ID 和路线完整性测试；
- 地图注记明确说明：现代地理底图仅作位置参考，不表示秦汉行政边界。

## 地图数据与限制

底图来自 [Natural Earth](https://www.naturalearthdata.com/) 的 1:110m 国家边界数据，并通过 `world-atlas` 随项目本地打包。Natural Earth 数据为公共领域数据。地图显示现代海岸线/国界参考，用于帮助理解事件的现代地理位置；它不是秦汉时期的政区复原图。

## 启动

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 验证

```bash
npm test
npm run build
```

## 目录

- `app/`：页面和全局样式；
- `components/`：地图、时间轴、统计和详情组件；
- `data/`：阶段与战争事件数据；
- `lib/`：类型及时间轴工具；
- `tests/`：单元测试。
