# 中国历史战争地图 · 秦统一至汉初

当前版本：v2.6.0（来源证据台与本地研究收藏）

v2.6.0 在两汉至三国专题的研究地图基础上增加播放游标连续性、标志性事件影像与史料引文、来源证据台和本地研究收藏。详见 [CHANGELOG.md](./CHANGELOG.md)。

一个以时间轴和动态地图呈现中国历史战争的数字人文可视化项目。现有两个相互隔离的专题：前 230 年至前 180 年的“秦统一至汉初”，以及前 202 年至 280 年的“两汉至三国”。后者以主线覆盖西汉、王莽与更始、东汉、汉末、魏蜀吴鼎立及西晋统一，不把未获授权的行政区面伪装为历史事实。

- 国际主站：https://war-map-sage.vercel.app
- 试验镜像：https://kuangami2.github.io/warMap/
- GitHub：https://github.com/kuangami2/warMap
- 当前技术栈：Next.js 16、React 18、TypeScript、Tailwind CSS、D3 Geo、TopoJSON、Vitest

## 当前功能

- 两个独立专题：秦统一至汉初，以及前 202 年至 280 年的两汉＋三国主线；专题、时间轴、搜索、分享与叙事播放互不串状态；
- 两汉＋三国专题含 55 条以上汉末/三国主线事件、40 个以上按年代显示的古地名参考点、25 个以上势力/活动范围快照和 29 节专题叙事；
- 公元前 230 年至公元前 180 年时间轴、战争叙事播放/暂停、0.5/1/2/4 倍速与阶段跳转；
- 基于 Natural Earth 1:10m 公共领域物理矢量数据的本地中国自然地理底图（海岸、湖泊、河流），不依赖地图 API Key；
- 学术图册式的三档地图信息密度：总览突出主河、都城/关隘与战略事件；区域补入郡国和河网；局部再显示县治与完整事件；
- 可开关的专题化地形图层：主要水系、山系、古风山形符号与明确的表达范围说明；
- 可按年代与缩放级别显示的古地名、城邑和关隘参考点，包含古今对照、来源与可信度说明；另有 Natural Earth 1:50m 公共领域现代地名参考层；
- 历史区域快捷定位、事件/古今地名搜索，以及可保存年份、事件、叙事节和地图视角的分享链接；
- 16 节来源可追溯的战争叙事：播放会按关键事件推进，自动聚焦战场/路线，同步展示摘要、来源、可信度及前后章节控制；
- 静态站点体积、压缩脚本和外部运行时资源的自动发布门槛，适配 Vercel 与 GitHub Pages；
- 冻结的历史数据契约、加强版来源/置信度验证，以及可恢复的分享链接跨端验收；
- 战争云团、事件节点、行军路线和事件详情联动；
- 播放叙事时自动启用轻量地图模式：保留事件、路线、古地名与势力语义，暂时简化高成本地形阴影、热区和柔边，退出叙事后恢复完整专业自然地理；
- 10 个关键事件的行军路线或多地点过程；
- 手机端单指拖动、双指捏合、双击放大，桌面端拖动与滚轮缩放；
- 事件标记与势力标签反向缩放：放大地图时保持可读、可点击，不会膨胀遮挡视野；
- 有边界约束的地图缩放、密集节点错位、按需标签、键盘操作和低动态模式；
- 桌面端和移动端响应式布局；
- 手机端首屏时间控制、粘性播放栏和可折叠地图图例；
- 微信、Android Chrome、iPhone WebKit 与桌面浏览器自动化矩阵；
- 事件年份、坐标、来源、重复 ID、事件性质、专题归属、势力层级与路线完整性自动测试；
- 势力区标签按控制层级和选中状态自动排序、避让；移动端优先显示核心及关联势力；
- 关键事件参与方显式维护势力 ID，不再完全依赖参与方名称推断；
- 无事件时间窗口提供明确的地图、叙事和统计空状态；
- 专题化数据读取接口、2.0 内容冻结审计与静态部署演练；没有外部运行时地图 API、瓦片、数据库或字体请求。

> 2.0 的正式定位是“专业自然地理＋历史地点＋势力范围＋战争叙事地图”。地图底图和 Natural Earth 现代地名仅用于现代地理定位；古地名为参考点。CHGIS 等已核对来源不允许静态再分发历史边界数据时，项目不渲染、不暗示、也不声称拥有精确历史行政区面。历史地点、路线和兵力存在争议时，项目明确标注不确定性，不把推断包装为精确事实。

## 本地运行

推荐使用 Node.js 24。

```powershell
cd D:\warMap
npm install
npm run dev
```

浏览器访问 `http://localhost:3000`。

## v1.9.8 / 2.0 发布候选说明

- 内容冻结：保留“秦统一至汉初”和“两汉至三国”两套相互隔离的专题数据；发布候选审计会统计两汉＋三国事件、地点、势力范围和叙事，并检查来源、许可证、静态产物和行政边界限制说明。
- 历史 GIS 授权闸门：经许可核对，CHGIS 数据不得再分发；未发现可公开展示且允许静态再分发的两汉三国行政边界包。因此本候选版本不含历史行政区面，且将地图控件从“郡县”调整为“古地名”，避免界面暗示行政边界能力。
- 现代定位补充：新增可开关的“今地名”层，使用本地化 Natural Earth 1:50m Populated Places（Public Domain）；只作古今定位参考，不参与历史行政 GIS。
- 发布演练：静态导出和 GitHub Pages 基础路径构建均可在本地执行；本次没有部署、提交或推送。实际 Vercel / GitHub Pages 发布仅在项目所有者再次授权后进行。
- 已知限制：自动化 Chromium 覆盖微信 Android 320、Android Chrome 375 和桌面布局；真实 iPhone Safari 390 / 414 的实机验收不由 Playwright 模拟替代。

## 目录

- `app/`：页面入口和全局样式；
- `components/`：地图、时间轴、统计和详情组件；
- `data/`：历史阶段与战争事件数据；
- `lib/`：类型、筛选和时间轴工具；
- `tests/`：数据与业务逻辑测试；
- `artifacts/`：本地视觉回归截图，不参与 Vercel 上传；
- `DEPLOYMENT.md`：部署配置和发布说明；
- `USER_DEPLOYMENT_GUIDE.md`：面向项目所有者的完整操作手册；
- `PROJECT_MANUAL.md`：项目范围、开发轮次和长期问题清单。
- `DATA_CONTRACT.md`：面向两汉＋三国 2.0 的历史数据、来源、不确定性与发布门槛。

## 部署状态

项目同时发布到 Vercel 和 GitHub Pages。Vercel 项目名为 `shining3/war-map`，并已连接 GitHub；推送 `main` 会更新国际主站。GitHub Pages 使用 `gh-pages` 静态分支作为无新增账号的试验镜像，可用 `npm run deploy:pages` 半自动更新。

GitHub Pages 已通过本机中国网络、香港与东京探测节点以及 Chromium/WebKit 浏览器矩阵，但不能保证所有中国大陆运营商均稳定可达，仍需用户所在网络最终验证。

详细步骤见 [USER_DEPLOYMENT_GUIDE.md](./USER_DEPLOYMENT_GUIDE.md)。
